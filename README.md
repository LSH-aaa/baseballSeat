# BaseballSeat-Projcet, 야구볼래?
프로야구 팬을 위한 커뮤니티 게시판 사이트입니다. JSP를 이용하여 간단히 제작하였습니다.
야구볼래는 각 구장별 좌석, 커뮤니키 게시판, QnA 게시판으로 이루어져 있습니다.

## 👨‍💻개발자 소개
- 송민지 : 팀장, 로그인/회원가입
- 정수현 :
- 이상헌 : 메인 페이지, QnA게시판, 오픈형 지도 API 불러오기

## 🕙개발 기간
- 2024.09.13 ~ 2024.09.27
- 아이디어 회의
- 중간 점검
- 발표 및 평가

## 💻개발 환경
- IDE : IntelliJ
- JDK

## ⚙️기술 스택
- frontend : HTML, CSS, JavaScript

- Database : MySQL, JDBC

## 🧩주요 기능
### ✔️ 로그인/회원가입
- JavaScript를 통한 유효성 검사를 통한 로그인, 회원가입 기능.
### ✔️ 메인 페이지
- 프로야구 구단의 사진 나열 후 hover 효과를 통해 구단 이름이 떠오르도록 스타일링.
- 클릭 시 해당 구단의 상세 설명 페이지로 이동.
### ✔️ 구단별 페이지
- 각 구장별 상세 위치 구글 API를 이용한 지도로 확인할 수 있음.
### ✔️ 커뮤니티 게시판
- 양도, 분실물 게시판
  - 글 번호, 카테고리, 제목, 작성자, 작성일, 조회수 정보를 표시.
  - 카테고리 별로 분류하여 게시판 리스트를 확인할 수 있음.
  - 검색 유형별(제목, 내용, 제목+내용)로 키워드 검색 시 키워드가 포함된 게시글을 검색할 수 있음.
- 게시글 작성/수정/삭제
  - 게시글 작성 시 사용자의 정보를 불러옴.
  - 게시글 작성 및 수정 시 제목 및 내용이 공란일 시 작성하도록 유효성 검사를 실시함.
  - 게시글을 작성한 사용자 이외에는 수정 및 삭제 불가능.
### ✔️ QnA 게시판
- 글 번호, 제목, 작성자, 작성일, 조회수의 정보를 표로 정리하여 표시.
- 제목을 클릭하면 QnA 상세페이지로 이동.
- 검색 유형(제목, 내용, 제목+내용)을 자유롭게 선택하여 검색창 이용 가능.
- 게시글 작성/수정/삭제
  - 게시글을 작성할 시 정보 입력란 표시.
  - 수정 페이지에 들어갈 시, 작성할 때 쓴 정보 불러오기. 수정 후 작성일은 수정한 기준 시간으로 업데이트됨.
  - 삭제하기 버튼을 눌러 해당 게시물 삭제.
