# BaseballSeat-Projcet, 야구볼래?
프로야구 팬을 위한 커뮤니티 게시판 사이트입니다. JSP를 이용하여 간단히 제작하였습니다.
야구볼래는 각 구장별 좌석, 커뮤니키 게시판, QnA 게시판으로 이루어져 있습니다.

## 👨‍💻개발자 소개
- 송민지 : 팀장, 로그인/회원가입
- 정수현 :
- 이상헌 :

- 중간 점검
- 발표 및 평가

## 💻개발 환경
- IDE : IntelliJ
- JDK
- Web Server : Apache Tomcat

## ⚙️기술 스택
- frontend : HTML, CSS, JavaScript
- backend : JSP, Servlet
- Database : MySQL, JDBC

## 🧩주요 기능
### ✔️ 로그인/회원가입
- JavaScript를 통한 유효성 검사를 통한 로그인, 회원가입 기능.
### ✔️ 메인 페이지
- 프로야구 구단의 사진 나열 후 hover 효과를 통해 구단 이름이 떠오르도록 스타일링.
- 클릭 시 해당 구단의 상세 설명 페이지로 이동.
### ✔️ 구단별 페이지
- 각 구장별 상세 위치 구글 API를 이용한 지도로 확인할 수 있음.
